# Natalia Lamkowska — strona główna

Strona: https://wordpress2389914.home.pl/autoinstalator/wordpressplus31/

`strona-glowna.html` zawiera HTML, CSS i JavaScript nowej strony głównej. W WordPressie zapisano ją jako blok HTML na stronie ID 75, z szablonem Elementor Canvas. Edycja odbywa się w kodzie bloku HTML, nie w pojedynczych widgetach Elementora.

Workflow `.github/workflows/films.yml` montuje dwa klipy baneru i przygotowuje osobny film między sekcjami. Pliki wynikowe są dostępne jako artefakt przez 3 dni; kopie używane przez stronę znajdują się w bibliotece mediów WordPressa. Workflow nie potrzebuje hasła WordPressa.

Zakres: strona główna, sześć sekcji, filmy z przyciskiem pauzy, menu mobilne, FAQ, kotwice, kontakt telefoniczny i e-mail. Karty nieruchomości prowadzą do zapytania e-mail. Nie wdrażano wyszukiwarki, bazy aktualnych ofert ani pozostałych podstron.

Sprawdzenie: widok desktop i mobilny, przewijanie, odtwarzanie filmów, menu i FAQ. Materiały wideo dostarczone przez właścicielkę projektu.
